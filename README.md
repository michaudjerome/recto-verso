# Recto Verso

Des cartes qui se retournent pour apprendre les langues : français, anglais, espagnol, italien, portugais, allemand et chinois, dans toutes les combinaisons.

Application web installable (PWA), 100 % hors ligne, sans compte ni serveur : tout reste sur le téléphone.

## Installer
Ouvrir https://michaudjerome.github.io/recto-verso/ puis :
› Android (Chrome) : menu ⋮ › « Ajouter à l'écran d'accueil ».
› iPhone (Safari) : bouton Partager › « Sur l'écran d'accueil ».
